# 班级积分管理系统 · Supabase 云端版 部署说明

这份说明教你**不用实名认证、不用绑定银行卡、不用满 18 岁**，把班级积分系统放到网上，
让全班学生用**同一套数据**（老师登记后，学生端、其他老师端都能实时看到）。

我们用的是 **Supabase**：免费额度足够一个班使用，只需要一个邮箱即可注册。

---

## 你需要的材料

| 材料 | 说明 |
|------|------|
| 一个邮箱 | 用于注册 Supabase（建议 QQ 邮箱、163 邮箱等） |
| 一个浏览器 | Chrome / Edge 均可 |
| 本目录的 2 个文件 | `schema.sql`（数据库脚本）、`index.html`（网页程序） |

> 全程**不需要**银行卡、**不需要**手机实名、**不需要**付费。

---

## 第 1 步：注册 Supabase 账号

1. 打开 https://supabase.com （英文网站，可用浏览器自带的翻译）
2. 点右上角 **Sign in** → 再点 **Sign up**
3. 选 **Sign up with Email**，输入邮箱和密码（密码要 8 位以上，含数字）
4. 邮箱会收到一封确认邮件（标题类似 Confirm your signup），点里面的**确认链接**即可

> 如果打不开或收不到邮件，可以用 **Sign up with GitHub** 代替（GitHub 也只需邮箱注册）。

---

## 第 2 步：创建项目（数据库）

1. 登录后进入控制台，点 **New project**（新建项目）
2. 填写：
   - **Name**：随便，如 `banji-jifen`
   - **Database Password**：设置一个数据库密码（**务必记下来**，以后可能用到）
   - **Region**：选离你最近的 **Southeast Asia (Singapore)** 即可（不用科学上网也能访问）
3. 点 **Create new project**，等待 1~2 分钟项目初始化完成

> 免费版项目如果 **7 天不使用会暂停**，下次进控制台点一下 **Restore** 即可恢复，数据不会丢。

---

## 第 3 步：运行数据库脚本（关键）

1. 左侧菜单点 **SQL Editor**（SQL 编辑器）
2. 点 **New query**（新建查询）
3. 用记事本打开本目录的 **`schema.sql`**，**全选复制**全部内容，粘贴到编辑器里
4. 点右下角 **Run**（运行），左下角显示绿色 **Success** 即成功

这一步会自动完成：
- 创建 4 张数据表（用户、学生、积分记录、积分规则）
- 设置权限（学生/组长只能看到自己的数据，防止越权）
- 创建 3 个初始账号（见文末）
- 写入 37 条默认积分规则

---

## 第 4 步：关闭邮箱验证（否则登录会提示"邮箱未确认"）

1. 左侧菜单点 **Authentication**（认证）→ **Providers**（登录方式）→ **Email**
2. 找到 **Confirm email** 开关，把它**关掉**（变成灰色）
3. 点 **Save**（保存）

---

## 第 5 步：获取连接信息

1. 左侧菜单点 **Project Settings**（项目设置）→ **API**
2. 复制两个值：
   - **Project URL**：形如 `https://xxxx.supabase.co`
   - **anon public key**：一长串字母数字（点右侧复制按钮）

---

## 第 6 步：填写程序并打开

1. 用记事本（或 VSCode）打开本目录的 **`index.html`**
2. 在文件开头找到这两行：
   ```js
   const SUPABASE_URL = 'https://你的项目.supabase.co';
   const SUPABASE_ANON_KEY = '粘贴你的anon public key';
   ```
3. 把第 5 步复制的两个值，分别替换进去（注意保留两侧的引号）
4. 保存文件，**双击用浏览器打开** `index.html` 即可登录使用

> `anon` 密钥是**公开的、可以放心放在网页里**的，真正的数据安全靠的是数据库权限（RLS），
> 学生即使看到这个密钥也无法越权修改他人数据。

---

## 第 7 步（可选）：发布到网上，生成一个网址

到这一步，**数据已经共享**了——只要每个设备打开同一个 `index.html`，看到的就是同一套数据。
如果你还想让大家**用一个网址**直接访问（不用发文件），推荐用免费的静态托管：

### 方案 A：GitHub Pages（推荐，免费、无需银行卡）

1. 注册 GitHub：https://github.com （邮箱即可）
2. 新建一个仓库（New repository），名字随便，选 **Public**，勾选生成 README
3. 进仓库 → **Add file → Upload files**，上传 `index.html`
4. 仓库 **Settings → Pages**，Source 选 **Deploy from a branch**，分支选 **main**，目录选 **/ (root)**，保存
5. 等待 1 分钟，页面会给出网址 `https://你的用户名.github.io/仓库名/`，点进去就能用

以后改了 `index.html`，重新上传覆盖即可更新。

### 方案 B：Vercel / Netlify（同样免费）

- Vercel：用 GitHub 账号登录 https://vercel.com → Import 你的仓库 → 自动发布
- Netlify：https://app.netlify.com → 直接把 `index.html` 拖进页面即可发布

## 怎么添加"小组记录员"

用 `admin` 登录 → 进入「用户管理」：

1. 用户名：填一个英文/数字（如 `zuzhang1`）
2. 密码：设置一个
3. 身份：填姓名（如 张三）
4. 角色：选 **小组管理**
5. 小组：填该记录员负责的小组名（**必须填**，这样他只能看/记本小组的数据）

> 小组名要和「学生管理」里学生的小组名**完全一致**，否则记录员看不到本组学生。

小组记录员的权限：
- 只看得见、只能管理**本小组**的学生和积分记录（由数据库权限自动限制，无法越权）
- 可以在「积分明细」里**编辑 / 删除（撤回）本小组的积分记录**；删除后记录会保留，但标记为"已删除"，并显示操作人和操作时间。修改/删除都会在明细的「修改信息」列留下记录。

## 常见问题

**Q1：登录提示"邮箱未确认"？**
去第 4 步确认已关闭 Email 的 Confirm email，并点保存。

**Q2：运行 schema.sql 报错说找不到某个列（如 `is_sso_user`）？**
说明你的 Supabase 版本较旧。跳过"运行脚本"里自动创建账号的部分，改为手动创建：
1. 左侧 **Authentication → Users → Add user**，用邮箱手动加 3 个账号
2. 邮箱填 `admin@banji.local` 等，密码自设
3. 再在 SQL Editor 里运行这段，给他们赋角色：
   ```sql
   update auth.users set raw_app_meta_data = jsonb_build_object('provider','email','providers',jsonb_build_array('email'),'role','admin','name','班主任') where email='admin@banji.local';
   insert into public.profiles (id, username, name, role) select id, 'admin', '班主任', 'admin' from auth.users where email='admin@banji.local';
   ```
   （其余 `banzhang@banji.local`、`tuanzhishu@banji.local` 同理，role 改为 `executive`。）

**Q3：免费额度够用吗？**
够。Supabase 免费版每月 5 万次 API 请求、500MB 数据库、1GB 流量，一个班级日常使用绰绰有余。

**Q4：数据会丢吗？**
正常不会。建议班主任定期在「设置 → 数据导出 → 导出备份」下载一份 JSON 留底。

**Q5：手机怎么用？**
用手机浏览器打开 `index.html`（或第 7 步的网址）即可，界面已经适配手机屏。
